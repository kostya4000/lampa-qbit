# Lampa — qBittorrent Direct

Плагин для [Lampa](https://lampa.mx/), который позволяет отправлять торрент-раздачи напрямую в [qBittorrent](https://www.qbittorrent.org/) без необходимости вручную копировать magnet-ссылки.

## Возможности

- ⬇️ **Добавление торрентов в один клик** — кнопка «В qBittorrent» появляется в карточке торрент-раздачи.
- 🔗 **Работа с magnet-ссылками** — передача magnet-ссылки непосредственно в qBittorrent через Web API.
- 📁 **Настройка пути сохранения** — можно указать базовую директорию для загружаемых файлов.
- 🗂️ **Категории** — назначение категории торрентам и автоматическое добавление категории к пути сохранения.
- ✏️ **Переименование** — использование названия раздачи в качестве имени торрента.
- 🔐 **Поддержка авторизации** — возможность передавать логин и пароль Web UI qBittorrent.
- ✅ **Проверка добавления** — проверка наличия торрента на сервере после отправки.
- 📺 **Управление с пульта** — поддержка навигации Lampa с помощью `hover:enter` и обычного нажатия.
- ⚙️ **Настройки внутри Lampa** — отдельный раздел qBittorrent и пункт быстрого доступа в главном меню.

## Установка

### Способ 1. Установка по ссылке

1. Опубликуйте файл JavaScript плагина в GitHub Pages.
2. Получите прямую HTTPS-ссылку на файл `plugin.js`.
3. Откройте Lampa.
4. Перейдите в настройки плагинов и добавьте полученную ссылку.
5. Перезапустите Lampa или дождитесь загрузки плагина.

Пример ссылки для GitHub Pages:

`https://USERNAME.github.io/REPOSITORY/plugin.js`

Замените `USERNAME` на имя пользователя GitHub, а `REPOSITORY` — на имя репозитория. Если файл находится в другой директории, укажите соответствующий путь.

### Способ 2. Подключение через GitHub Pages

Если репозиторий уже создан:

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе публикации выберите **Deploy from a branch**.
4. Укажите ветку `main` и директорию `/ (root)`.
5. Нажмите **Save**.
6. Дождитесь публикации сайта и используйте выданный адрес GitHub Pages.

Покупать собственный домен для публикации не требуется.

## Настройка qBittorrent

Перед использованием необходимо включить Web UI в qBittorrent.

1. Откройте настройки qBittorrent.
2. Перейдите в раздел **Web UI**.
3. Включите веб-интерфейс и укажите порт, например `8080`.
4. Настройте доступ с устройства, на котором работает Lampa.
5. Проверьте доступность адреса Web UI из локальной сети.

Пример адреса:

`http://192.168.1.50:8080`

Укажите вместо этого адрес своего сервера.

### Авторизация

Плагин поддерживает два режима:

- **Обход аутентификации** — включён по умолчанию. Предполагается, что для подсети настроен соответствующий обход авторизации в qBittorrent.
- **Обычная авторизация** — отключите обход и укажите логин и пароль Web UI.

Не открывайте Web UI qBittorrent в интернет без надлежащей защиты. По возможности ограничьте доступ локальной сетью или используйте защищённый обратный прокси.

## Настройки плагина

Все параметры находятся в разделе **Настройки → qBittorrent**.

| Параметр | По умолчанию | Описание |
|---|---|---|
| Адрес сервера | `http://192.168.1.50:8080` | Адрес Web UI qBittorrent |
| Логин | Пусто | Имя пользователя для авторизации |
| Пароль | Пусто | Пароль Web UI |
| Обход аутентификации | Включён | Использование настроенного обхода авторизации для подсети |
| Базовый путь сохранения | Пусто | Каталог для загрузок |
| Категория | Пусто | Категория для добавляемых торрентов |
| Автоматически добавлять категорию к пути | Включено | Сохранение загрузок в подпапке категории или использование автоуправления qBittorrent |
| Переименовывать | Включено | Передача названия раздачи в qBittorrent |
| Проверять добавление | Включено | Проверка наличия добавленного торрента |

### Пример настройки пути

Допустим, в настройках указано:

- Базовый путь: `/app/qBittorrent`
- Категория: `video`
- Автоматически добавлять категорию к пути: включено

Итоговый путь сохранения:

`/app/qBittorrent/video`

Если базовый путь не указан, плагин включает `autoTMM` для категории, чтобы qBittorrent использовал назначенный ей путь согласно собственным настройкам.

**Важно:** путь указывается в файловой системе, доступной самому qBittorrent. Если сервер работает в Docker, необходимо использовать путь внутри контейнера, соответствующий смонтированному тому.

## Как пользоваться

1. Откройте в Lampa карточку торрент-раздачи.
2. Найдите кнопку **⬇ В qBittorrent**.
3. Нажмите её с помощью пульта или мыши.
4. Плагин передаст magnet-ссылку в qBittorrent.
5. Если включена проверка, плагин попробует подтвердить наличие торрента на сервере.

После успешного добавления загрузка выполняется самим qBittorrent. Lampa не загружает торрент-файлы самостоятельно.

## Устранение неполадок

### Плагин не появляется

- Проверьте правильность URL JavaScript-файла.
- Убедитесь, что GitHub Pages успешно опубликовал репозиторий.
- Проверьте консоль браузера на ошибки загрузки и выполнения JavaScript.
- Перезапустите Lampa.

### Не удаётся подключиться к qBittorrent

- Проверьте адрес и порт Web UI.
- Убедитесь, что сервер доступен из сети устройства с Lampa.
- Проверьте правила межсетевого экрана и настройки авторизации.
- Убедитесь, что qBittorrent запущен.

### Ошибка 403 Forbidden

Проверьте настройки авторизации qBittorrent. Если используется обход аутентификации для локальной подсети, убедитесь, что IP-адрес клиента Lampa попадает в разрешённый диапазон.

### Торрент отправляется, но подтверждение не приходит

В некоторых средах Lampa не может получить ответ от Web API из-за ограничений HTTP-запросов, CORS или особенностей встроенного браузера. В таком случае плагин может сообщить об отправке без подтверждения.

Если используется HTTP-адрес сервера, а сама Lampa открыта через HTTPS, браузер также может блокировать запросы из-за политики смешанного содержимого.

### Торрент добавился не в ту папку

- Проверьте базовый путь сохранения.
- Убедитесь, что категория существует или может быть создана в qBittorrent.
- Проверьте настройки путей категорий и автоматического управления торрентами.
- Для Docker проверьте соответствие путей внутри контейнера и на хосте.

## Технические детали

Плагин использует Web API qBittorrent:

- `POST /api/v2/torrents/add` — добавление magnet-ссылки.
- `POST /api/v2/auth/login` — авторизация.
- `GET /api/v2/torrents/info?hashes=...` — проверка наличия торрента.

Плагин реализован на JavaScript и взаимодействует с API Lampa для регистрации настроек, добавления пункта меню и обработки событий карточки торрент-раздачи.

## Безопасность

- Не публикуйте логин и пароль qBittorrent в репозитории.
- Не открывайте Web UI в интернет без защиты.
- Используйте ограничение доступа по IP, VPN или защищённый обратный прокси.
- Учитывайте, что обход авторизации снижает уровень защиты Web UI и должен применяться только в доверенной сети.
